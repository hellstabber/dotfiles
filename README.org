* My Personal Dotfiles
  managed by [[https://chezmoi.io][Chezmoi]]

** Goals
   - Minimal and distraction-free Linux environment
   - Reproducible workstation setup
   - Consistent configuration across my machines

** Setup
   - Arch Linux
   - Sway
   - Waybar
   - Fuzzel
   - Mako
   - Ghostty
   - Zsh
   - Helix
   - Emacs
   - LibreWolf

** Provisioning
   - Ansible for packages and services
   - Chezmoi for dotfiles

** Install
#+begin_src sh
chezmoi init hellstabber/dotfiles
cd ~/.local/share/chezmoi
./bootstrap
#+end_src
