* My Personal Dotfiles
  managed by [[https://chezmoi.io][Chezmoi]]

** Goals
   - Distraction-free CLI environment
   - Efficient reading/writing and note-taking with Emacs
   - Consistent experience across Arch Linux and macOS

** Tools
   | Category           | Application  | Config                  |
   |--------------------|--------------|-------------------------|
   | Shell              | Zsh + OMZ    | dot_zshrc               |
   | Terminal           | Ghostty      | dot_config/ghostty      |
   | Window Manager     | Sway         | dot_config/sway         |
   | Status Bar         | sway-bar     | dot_config/sway/scripts |
   | Text Editor        | Neovim       | dot_config/nvim         |
   | Text Editor        | Doom Emacs   | dot_config/doom         |
   | Notifications      | Dunst        | dot_config/dunst        |
